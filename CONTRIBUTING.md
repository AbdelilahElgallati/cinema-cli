# Contributing to CinePro CLI

Thanks for wanting to contribute! We welcome bug reports, documentation improvements, and code contributions.

Getting started
- Fork the repo and create a feature branch from `main`.
- Run the project locally (see README). Make changes in a branch and open a PR when ready.

Code style
- Python: we use `black` for formatting and `isort` for imports. Run `black .` before committing.
- JavaScript/Node: we prefer `prettier` for formatting.

Testing & linting
- Add tests under `cli/tests/` or `backend/tests/` as appropriate.

Pull Request process
- Keep PRs small and focused.
- Provide a clear description and testing steps.
- Link any relevant issues.

Communicating
- Use issues for bugs and feature requests.
- For quick coordination, open an Issue and mention maintainers.

Thanks — your improvements make this project better for everyone.
